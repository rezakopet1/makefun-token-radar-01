Token Radar (radar-2): a program that reads the sealed DefiLlama snapshot and ranks every pre-token protocol by an implied token value derived from the snapshot's own figures — TVL, seven-day growth, age with no token, and a category multiple read from the tokened protocols themselves — with a concrete farm plan for each one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
